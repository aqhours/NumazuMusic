# Yomikana Mac 应用

Mac 版使用 Tauri 2 + 系统 WebView。桌面入口位于 `desktop/`，复用网站的歌曲库、歌词阅读器和音频数据；独立 Vite 构建不依赖 Cloudflare 或本地 Web 服务。网站原来的开发、部署方式保持不变。

## 使用

主窗口保留 macOS 原生红黄绿按钮，标题栏以透明叠加方式覆盖页面，背景延伸到窗口顶部。页面布局与样式保持原样。窗口顶部中央设有无底色、无布局占位的拖动区域，避开左右两侧按钮；歌曲库、歌曲页和阅读界面均可从这里拖动窗口。

打开 Yomikana.app，选择歌曲 → 开始阅读 → 播放。在 Mac 顶部菜单栏选择「显示 → 悬浮歌词」，勾选即开启，再次点击关闭。此入口仅在 Mac 应用中提供。字幕默认显示在主窗口所在屏幕的下方，黑色背景不透明度为 55%，显示当前日文原行和中文译文。前奏显示音符和歌名；一句唱完后保留该句，直到下一句开始，暂停时也保留当前字幕。

鼠标移入字幕窗后，工具栏直接覆盖在歌词上：拖动手柄、上一首、播放/暂停、下一首、字号、锁定和关闭。功能区显示时歌词变暗、透明度增加，移开后恢复，黑底不因工具栏出现而变大。锁定开启鼠标穿透；在 Mac 顶部菜单栏选择「显示 → 解锁悬浮歌词」即可恢复拖动。重新开启字幕也会解锁，并将窗口移回当前屏幕，避免更换显示器后找不到窗口。使用工具栏的拖动手柄移动窗口，歌词和黑底不响应拖动。黑底根据歌词、字号和译文自动收紧，窗口同步适配内容，长句按屏幕宽度换行；字号会保存。黑底固定为 55% 不透明度，译文始终显示；中日文字号和字重一致。

Mac 播放模式使用全曲库随机队列：每轮打乱所有歌曲，播完当前歌曲自动接续下一首，轮次交界不连续重复同一首。上一首返回实际播放历史；回退后点击下一首会沿历史前进。手动从歌曲库选歌会重建队列。第一首歌曲没有历史时，上一首不可用；加载音频时播放/暂停不可用，但可以继续切歌。

关闭歌词阅读界面会暂停播放；关闭 Mac 主窗口会退出应用和字幕窗。字幕跟随 Yomikana 内的播放，不读取其他音乐软件。

主播放器工具栏的「导出歌词卡片」支持选句、日语/中文/双语和两种卡片样式。点击「保存图片」后，PNG 保存到系统下载文件夹；同名图片自动追加编号，保留之前的导出。此功能需要重新编译包含 `save_lyric_card` 命令的 Mac 应用。

## 开发和打包

应用要求 macOS 14+，用于禁用 WebView 后台节流，持续同步字幕。开发需要 Node.js 22.13+、Rust stable、Xcode Command Line Tools。

```sh
npm install
npm run mac:dev
```

也可以使用 `npm run tauri dev`，两者等价。开发模式会自动启动 Vite；修改 React/CSS 会热更新，修改 Rust 会增量编译并重启应用，无需生成安装包。首次开发启动仍需编译 debug 版本。

```sh
npm run desktop:build  # 桌面前端
npm run desktop:check  # 桌面 TypeScript 检查
npm run mac:check      # Rust 编译检查
npm run mac:build      # .app 和 .dmg，默认当前机器架构
```

产物位于 `src-tauri/target/release/bundle/`。打包会包含 `public/` 中的本地音频和时间轴；远程封面仍需网络。发布给其他 Mac 用户之前，需要另行配置 Developer ID 签名和公证；本项目尚未配置发布证书。

透明窗口启用 `macOSPrivateApi`，适用于站外分发，不用于 Mac App Store。参见 [Tauri 窗口配置](https://v2.tauri.app/reference/config/)。

## 同步机制

切歌保留同一个音频元素与分析器，取消过期的音频和时间轴请求，并清空上一首的时钟、字幕与错误状态。悬浮窗的播放控制经 Rust 定向发送给主播放器，播放状态随字幕快照同步。

主窗口读取实际 `HTMLAudioElement.currentTime`，结合原有对齐后的行时间范围生成字幕，通过 Rust 保存最新状态并发送至字幕窗。仅在字幕变化时发送 IPC；字幕窗启动时读取缓存，避免错过首次事件。音频事件和独立计时器共同更新字幕，不依赖主窗口的 requestAnimationFrame。网页环境不会启用桌面通信。

## 人工验收

构建、类型和代码检查不代表 UI 验收通过，请在 Mac 应用内检查：

- 播放、暂停、拖动进度、随机队列跨轮次和切换歌曲后，字幕与声音一致；句间空隙保留当前句，不闪回歌名；切到新歌前奏时清除上一首歌词。
- 切到其他应用、最小化主窗口后，音频和字幕继续更新。
- 黑底透出桌面，中日文字号和字重一致、译文始终显示；黑底随文字和字号收紧，长句正常换行。
- 手柄拖动（歌词和黑底不响应拖动）、自动调整大小、锁定穿透、菜单栏解锁、关闭后重开均正常。
- 更换显示器、切换桌面及进入其他应用的全屏空间时，检查置顶行为。macOS 全屏空间有独立的窗口层级，需要实际确认覆盖效果。
- 自动播完接续下一首；悬浮窗上一首按历史回退、下一首继续随机队列、播放/暂停图标与实际状态一致。快速切歌和音频加载失败时不串歌，关闭阅读界面后不自动恢复播放。
- 功能区覆盖歌词时文字变淡，移开鼠标后恢复；工具栏出现不改变黑底尺寸。
- 首页、歌曲页、阅读界面的背景延伸至顶部，没有独立标题栏底色；红黄绿按钮可正常使用，顶部中央可拖动窗口且不遮挡左右按钮，全屏进出正常。
- 关闭主窗口后没有残留字幕窗口。
- 打开「导出歌词卡片」，切换语言和样式，选择不连续的歌词并保存；检查下载文件夹中的 PNG 与预览一致，重复保存不会覆盖旧图。制作期间自动切歌仍保留原歌曲，Esc 只关闭卡片并返回阅读器。

按项目约定，不使用浏览器或原生应用自动化进行界面验收。
